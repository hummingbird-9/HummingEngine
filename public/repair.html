Manual recovery if a database stays blocked

Chrome sometimes keeps a connection alive after a page or service worker is closed. A different Google account does not itself fix a damaged database in this browser profile.

  1. Close every tab at hummingproxy.onrender.com in this Chrome profile.
  2. Open Chrome's site information icon beside the address bar, choose Site settings, and clear stored site data for hummingproxy.onrender.com. Or open chrome://settings/content/all, search for hummingproxy.onrender.com, and delete its site data.
  3. Return to the proxy and reload. Clearing site data also removes locally saved HummingProxy tabs, bookmarks, and settings.

If the exact same missing-object-store error occurs on a brand-new Chrome profile, the problem may be HummingProxy/Scramjet initialization, not old stored data. In that case the site code needs a separate fix.
