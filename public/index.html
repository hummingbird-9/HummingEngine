Try first: Wait for Render to wake up, then press Retry. If pages still fail after the site wakes, clear this site's data.

      
How to clear site data in Chrome / Chromebook
        
  1. Open HummingProxy directly in its own tab.
  2. Click the icon to the left of the address bar, then Site settings.
  3. Choose Clear data or Delete data for this site (wording varies), then reload HummingProxy.
  4. If that option is missing, open Chrome Settings → Privacy and security → Site settings → View permissions and data stored across sites; find hummingproxy-saj5.onrender.com and delete its stored data.

        
Warning: Clearing site data may remove saved tabs, bookmarks, settings and appearance customizations. Clearing only cached images/files may not repair IndexedDB.
